# 🚗 Car Price Prediction App (Streamlit)

This is a simple and interactive **web application** that predicts the estimated price of a second-hand car based on user-inputted vehicle details.

The app was developed using **Streamlit** and is backed by a machine learning model trained on a dataset collected from real-world second-hand car listings in Turkey.

## 🎯 Purpose

The aim of this project is to help users get a quick estimate of a vehicle's market value using machine learning. By entering basic car information such as brand, model, mileage, engine size, and more, users can instantly view a predicted price.

While this tool provides valuable insights, please note:

> ⚠️ **Disclaimer**: This is a simplified prototype, and predictions are for informational purposes only. The model may not reflect current market prices precisely. Further improvements and data enhancement would be needed for production-level accuracy.
